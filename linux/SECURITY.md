# Security Policy

## Reporting a vulnerability in this tool

If you find a security issue in H2Shield itself (not the CVE it addresses), please open a GitHub issue marked **[SECURITY]** or contact the maintainer directly.

Please do not report vulnerabilities in nginx, Apache, or other third-party software here — report those to their respective maintainers.

## Scope of this tool

H2Shield is a defensive auditor and hardener. It does not contain exploit code. If you believe a contribution has introduced offensive capability, report it immediately.
